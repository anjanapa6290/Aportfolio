# Elegant Minimal Portfolio

A responsive portfolio made with plain HTML, CSS, and JavaScript. No framework or build tools are required.

## Run it locally
1. Extract the ZIP file.
2. Open the `elegant-portfolio` folder in VS Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.
4. Edit `index.html` to update your name, email, skills, certificates, project descriptions, and social links.
5. Edit `style.css` to change colors, spacing, or typography.

## Publish to Vercel
1. Create a new GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. In Vercel, choose **Add New → Project** and import that GitHub repository.
4. For a plain static HTML site, no build command is needed. Deploy it.
5. After deployment, open the Vercel project settings and connect your existing domain if you want to replace the current site.

## Important before publishing
- This starter uses the name and email shown on the linked portfolio. Change them if this portfolio is for a different person.
- Replace example project cards and generic GitHub/LinkedIn links with real project and profile URLs.
- Check that every certificate link works.
- A mailto link opens the visitor's email app; it is not a backend contact form.
